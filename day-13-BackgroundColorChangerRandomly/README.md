# 🎨 Random Color Generator

A simple React app that generates random background colors.

## 🚀 Features

* Manual color change on button click
* Auto color change using timer (`useEffect`)
* Start/Stop toggle

## 🛠️ Tech

* React
* JavaScript

## ▶️ Run locally

```bash
npm install
npm run dev
```

## 💡 What I learned

* useState for state management
* useEffect for intervals and cleanup
* Generating random HEX colors
